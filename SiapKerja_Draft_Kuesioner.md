## Form 1 — Pra-simulasi (peserta, menit 0–8)

Judul Form: **SiapKerja uji coba — sebelum bermain**  
Pengantar: *Isi sebelum memulai simulator. Kami mengevaluasi aplikasi, bukan menilai Anda. Jangan tulis nama orang atau nama instansi.*

| No | Butir | Tipe |
|---|---|---|
| 1 | Kode responden (contoh R07) | isian, wajib |
| 2 | Kode kelompok (contoh G2) | isian, wajib |
| 3 | Jenis organisasi Anda (jangan tulis nama instansi) | pilihan: kontraktor / konsultan / kampus atau politeknik / asosiasi / individu / lainnya |
| 4 | Peran Anda saat ini | pilihan: perencana / last planner atau mandor / engineer lapangan / lean specialist / dosen atau mahasiswa / lainnya |
| 5 | Pengalaman kerja konstruksi | pilihan: belum / <3 th / 3–7 th / 8–15 th / >15 th |
| 6 | Pernah menjalankan Last Planner System di proyek nyata? | pilihan: tidak / pernah melihat / pernah menjalankan |
| 7 | Seberapa familiar dengan istilah LPS (last planner, pull, make-ready, PPC)? | pilihan: belum pernah mendengar / pernah mendengar / pernah dipelajari di kelas atau kantor / pernah dipakai di lapangan |
| 8 | Bagaimana pekerjaan mingguan biasanya direncanakan di tempat Anda bekerja atau belajar? | pilihan: jadwal induk atau Gantt / rapat lapangan informal / sudah memakai LPS / belum bekerja atau belajar di lapangan / lainnya |
| 9 | Jadwal induk (Gantt/CPM) sudah cukup untuk mengendalikan produksi mingguan. | Likert 1–5 |
| 10 | Pekerjaan minggu depan boleh dijanjikan meskipun masih ada kendala yang belum dilepas. | Likert 1–5 |
| 11 | Last planner adalah orang yang paling dekat dengan pekerjaan, bukan hanya planner di kantor lapangan. | Likert 1–5 |
| 12 | PPC mengukur seberapa cepat bangunan diselesaikan. | Likert 1–5 |
| 13 | Pull berarti memulai setiap kegiatan seawal mungkin sesuai jadwal induk. | Likert 1–5 |
| 14 | Make-ready (menyiapkan agar pekerjaan SiapKerja) lebih menentukan keandalan janji daripada menambah tenaga di hari H. | Likert 1–5 |

**Kunci olah (jangan tampilkan di Form):** butir 9, 10, 12, 13 = terbalik (6−x). Butir 11 dan 14 utuh. Indeks cara pandang LPS pra = rata-rata 1–5.
